Gestão de Imagens

A imagem marcada com a Estrela Dourada é definida como a Capa do Produto. Esta é a imagem principal que aparecerá:

  • Na vitrine inicial do site.
  • Nos resultados de busca.
  • Como primeira imagem na página de detalhes do produto.

Ação Automática: Ao clicar na estrela (ou na estrela cinza de outra foto), o sistema automaticamente define aquela imagem como capa e a move para a primeira posição da lista.

A ordem das fotos no painel administrativo é exatamente a ordem que será exibida para o cliente no site. Para organizar:

  1. Clique e segure sobre a foto desejada.
  2. Arraste-a para a posição correta.
  3. Solte para salvar a nova ordem automaticamente.

Dica Importante: Se você arrastar qualquer foto para a Primeira Posição, o sistema entenderá que ela deve ser a nova capa e atualizará a estrela automaticamente.

Cores e Filtros

No cadastro do produto, existem dois campos relacionados à cor, e cada um tem uma função vital:

  • Campo "Cor" (Texto): Este é o nome que aparece escrito para o cliente (Ex: "Azul Marinho", "Rosa Neon"). Ele serve para identificação verbal.
  • Campo "Cor Hex" (Seletor Visual): Este é o código visual da cor. No site, ele aparece como uma "bolinha colorida" que permite ao cliente clicar para filtrar ou selecionar a variação.
Atenção: Se você não selecionar a Cor Hex correta no seletor, a bolinha no site ficará preta (padrão) ou com a cor errada, confundindo o cliente na hora de filtrar.
Nomenclatura de Produtos

Para manter o site organizado e profissional, siga este padrão ao nomear produtos:

Tipo + Característica Principal

Exemplos Corretos:

  • Legging Montaria Cirrê
  • Top Nadador Suplex
  • Conjunto Fitness Poliamida

Evite colocar a cor no nome do produto (Ex: "Legging Preta"), pois o cliente selecionará a cor através das opções de variação. Mantenha o nome "limpo" para agrupar as variações corretamente se necessário.

Categorias do Site

As categorias cadastradas ("Leggings", "Tops", "Shorts") transformam-se automaticamente nos menus de navegação do site.

Importante:

  • Evite criar categorias duplicadas com nomes ligeiramente diferentes (Ex: "Legging" e "Calça Legging"). Isso fragmenta os produtos no site.
  • Produtos sem categoria podem não aparecer nas buscas principais. Sempre classifique cada item.
